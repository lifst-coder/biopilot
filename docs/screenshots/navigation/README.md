# 화면 사이 이동 — 막힘 지점과 조치, 전후 비교 (lab 데모, 1440 / 768 / 390 px)

데모 빌드(`VITE_DEMO=true`, lab 시나리오)를 띄워 여섯 탭을 직접 돌며 "여기서 다음에 하고 싶은 것이 있는데 갈 수 없다"
지점을 찾았다. 순회 스크립트는 화면마다 `<main>` 안의 실험 코드(`#024`, `#OA06`) 중 **링크가 아닌 것**의 수,
`scrollWidth > clientWidth`(가로 스크롤), 콘솔 오류를 함께 기록했다. 스크린샷은 안내 바를 닫은 상태의 첫 화면이다.

## 1. 찾은 막힘 지점과 조치

### 실험 코드를 눌러서 갈 수 없었다

| 어디서 | 이전 | 이후 |

| Records 실패 아카이브 — 반복 연결(`#024 → #028`), 벗어난 실험, 원인 가설·메모 발췌, 결정 사유·후속 실험 제목 | 27개가 글자 | 0 |
| Protocols 버전 설명 · "계기 실험 #017" | 글자 5개 | 0 |

| 비교 모달 `#024 → #028`, Analysis·Overview "기준 실험 #018은 89.1%", Partner 패널 컨텍스트·최근 비판 | 글자 | 링크 |
| Overview 회수율 추이 그래프 | 점을 눌러도 아무 일 없음 | 점을 누르면 그 실험 기록 |

구현: `lib/experimentIndex.ts`(모든 프로젝트의 실험 목록을 코드→id·프로젝트로, 기존 `useExperiments` 캐시 공유) +
`components/CodeText.tsx`(문장 속 코드만 `ExperimentLink`로, 저장된 실험이 아닌 `#79` 같은 결과 번호는 그대로).

### 이동하면 맥락을 잃었다

- **어디서 왔는지 보이지 않고 돌아갈 곳이 없었다** → 맥락 줄 맨 앞에 `← Records · 실패 아카이브`. 브라우저 기록 위치마다
  화면 이름을 기억(`lib/trail.ts`, sessionStorage)해 한 칸 뒤가 **다른 화면일 때만** 보인다. 누르면 브라우저 뒤로와 같다.
  근거 칩·문장 속 코드·안내 바·탭·검색 결과 등 어떤 링크로 왔든 동작한다.
- **지금 무엇을 보는지 한 줄** → 모든 화면 상단 `잔류농약 · #024 · 2026. 10. 20. · SOP v2 · ✕ QC 불합격`
  (`layout/ContextBar.tsx`). 프로젝트 → Overview, 코드 → Notebook, 날짜 → Overview 타임라인(그 행 강조),
  `SOP v2` → Protocols에서 **그 버전이 펼쳐진 채로**, QC → Analysis. QC는 기호(✕ ! ✓ –)와 글자를 함께 쓴다.
  프로젝트 화면은 `잔류농약 · 실험 30건 · 버전 계보`, Records 전체 범위는 `모든 프로젝트 · 저장된 기록 전체 · 실패 아카이브`.

### 다음 행동이 막혀 있었다

| 화면 | 이전 | 이후 |
|---|---|---|
| Protocols 버전 계보의 불합격 실험(#024·#026·#028) | 칩을 누르면 Notebook으로만. "왜 실패했나"까지 두 번 더 이동 | 줄 끝에 `왜 실패? 판정 근거 · AI 비판` (Analysis / Research AI #critic) |
| Records 실패 아카이브의 반복 패턴 | 반복된 실험들이 **어떤 조건이 달랐는지** 볼 수 없음 | 접힌 `조건 차이 비교` — 반복 실패와 벗어난 실험의 값이 다른 조건만(Memory `compare-conditions`), 벗어난 실험 값은 굵게. 연결마다 `나란히 비교`(두 실험 비교 모달) |
| Records 작업자 차이 목록 | 맨 위 발견에만 비교 링크, 나머지 쌍은 칩뿐 | 쌍마다 `두 실험 비교 →` |
| Critic 누락 대조군 | 그 대조군을 다루는 제안이 어디 있는지 알 수 없음 | `이 대조군을 포함한 제안 P6 · 결정 대기 →`(설계의 `addresses_controls`) — 누르면 그 제안 카드로 스크롤·포커스. 없으면 "아직 없습니다" |
| Research AI, 비판이 없는 실험(데모 42개 중 35개) | "실행 버튼을 누르세요"(데모에서는 실행 불가) | 무엇이 없는지 + `비판이 저장된 실험 #024 #009 #006` 링크 |
| Partner 패널 최근 비판 | Research AI로 가는 길 없음 | `근거·누락 대조군·제안 보기 → Research AI`, 비판이 없으면 실행하러 가는 링크 |
| 헤더(1024–1440 px, 안내 바를 닫은 데모) | **Records 탭이 잘려 보이지 않고** "안내" 버튼이 세로로 꺾임(작업 전 스크린샷 참고) | 헤더가 두 줄로 접혀 탭 6개가 모두 보인다 |

### 빈 상태와 오류 문구

| 상황 | 이전 | 이후 |
|---|---|---|
| 분석 안 된 실험 (Analysis) | "저장된 분석 결과가 없습니다." | 무엇이 없는지 + CSV가 있으면 `#… 분석 실행`, 없으면 `CSV 올리러 Notebook으로 →` |
| 분석 안 된 실험 (Notebook) | "아직 분석되지 않았습니다." | 같은 두 갈래의 다음 행동 |
| 과거 사례 없음 (불합격 실험) | 카드가 사라질 뿐 | "과거 사례 없음 — 모든 프로젝트에서 찾지 못했습니다. 이번 판단과 사유를 결정으로 남기면 다음 실패 때 여기에 나옵니다." |
| 새 프로젝트(실험 0개) Overview | 빈 그래프·빈 표 | "아직 실험이 없습니다" + `+ 새 실험 기록 → Notebook` · `프로토콜 붙여넣어 시작 → Protocols` |
| 제안·가설·결정 없음, 검색 결과 없음, 회수율 결과 없음 | "제안 없음" 등 | 무엇이 없고 어떻게 채우는지 한 줄 |
| 오류 | `오류: Failed to fetch`, `오류: boom` | 다음 행동이 먼저: "서버에 연결하지 못했습니다 — 백엔드(uvicorn)가 켜져 있는지 확인하고 새로 고치세요", 코드별(not_found·validation_failed·revision_conflict·payload_too_large·500 …) 안내 + `서버 응답: …` |

### 키보드

`1`–`6` 탭 전환 · `[` `]` 이전/다음 실험(Notebook·Analysis·Research AI) · `/` 기록 검색 · `?` 단축키 목록
(맥락 줄 오른쪽 `단축키 ?`로도 열린다, 768 px 이상). 입력 칸에서는 동작하지 않는다.
