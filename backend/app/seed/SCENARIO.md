# Seed scenario — "6개월간 축적된 연구실"

원본(메모·조건 블록·CSV 배정)은 `data/residue.json`, `data/organic_acids.json`, AI 비판·연구자 결정 이력은
`data/history.json`. CSV는 `generate.py`(고정 난수 시드, 파일별 독립 스트림)로 재현되며
`tests/test_seed.py`가 커밋된 파일과의 일치를 검사한다. 스펙 스키마는 `spec.py`.

## 프로파일

| 프로파일 | 내용 | 사용처 |
|---|---|---|
| `reference` (기본) | 잔류농약 #018–#024 (7개, #018이 루트), #024 규칙 비판 1건 | `seeded`/`client` 픽스처, 모듈 테스트, 기본 auto-seed |
| `lab` | 프로젝트 2개 · 실험 42개 · 비판 7건 · 결정 12건(기각 5) | `tests/test_seed_lab.py`, 데모/로컬 실행 |

```bash
BIOPILOT_SEED_PROFILE=lab uvicorn app.main:app --reload      # 빈 DB일 때 lab으로 auto-seed
python -m app.seed --profile lab --database-url sqlite:///./lab.db
```

`reference`의 원본과 CSV 12개는 확장 전 시드와 **바이트 단위로 동일**하다(`ORIGINAL_SHA256` 테스트).
`lab`에서는 같은 #018–#024가 SOP v2 전환 실험(#017) 아래에 매달린다.

## 공통 요소 (프로젝트 간 회상의 근거)

- 작업자 2명: **김연구**(수동 진탕 1분·원심 3000 rpm 5분·IS를 최종 추출액에 첨가 / 유기산은 초음파 후 바로 여과)
  vs **이분석**(시료 수화 10분·기계식 진탕기·원심 4000 rpm 10분·IS를 추출 전 첨가 / 원심 후 여과).
  습관은 조건 블록이 아니라 메모와 데이터(반복 간 편차)에 남는다 → 같은 조건의 #029/#030 비교로 드러난다.
- 같은 LC-MS/MS(농약 ESI+, 유기산 ESI−), 7/13–8/3 기기 점검으로 **두 프로젝트 모두** 중단.
- 같은 C18 1.8 µm 컬럼을 6–7월에 공유 (#OA02 100% 수계 사용 → #011 테일링 메모), #OA04에서 전용 컬럼으로 분리.
- 같은 내부표준 TPP로 시작 → 유기산은 #OA08에서 숙신산-13C4로 교체(ESI− 억제 미보정).
- 농약 SOP의 PSA 정제를 유기산에 가져와 실패(#OA06) — PSA는 유기산을 제거하는 흡착제.

## 노이즈·결측·이상치 (generate.py 설계 표에 명시)

- 결측: 미보고 피크 행(#002 S-07 thiabendazole, #OA11 S-07 fumaric acid), 미주입(#OA03 S-05), 시퀀스 중단(#012 S-07~S-10).
- 이상치: 이중 첨가(#007 S-04), 간섭(#013 CAL-03 imidacloprid), 첨가 오류(#OA06 S-03 citric acid). 원본 보존, 제거하지 않는다.
- 숫자 칸을 비워 두는 결측은 쓰지 않는다 — 현재 Analysis가 NaN을 처리하지 않는다(CHANGES_REQUESTED.md).

## 결정 이력과 반복 금지 검증

`history.json`의 `decisions`는 (실험, 제안이 바꾸는 조건 키 집합)으로 비판의 제안을 특정한다. 기각 사유는
저장된 rationale 앞에 `[예산]`처럼 붙는다. `repeat_probes`는 "그대로 다시 비판하면 기각된 제안이 다시 나올"
실험 목록이며 `test_critic_does_not_repeat_rejected_proposals`(현재 xfail)가 Partner의 반복 여부를 검사한다.
결정 시각(`created_at`)은 시드 실행 시각이다 — 과거 시점 기록 API가 없다(CHANGES_REQUESTED.md).
