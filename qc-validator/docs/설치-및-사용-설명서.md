# 설치 및 사용 설명서

BIOPILOT · 분석 엔진 v1.0.0 · 생성일 2026-11-11 · `node scripts/gen-docs.mjs`가 만든 문서다.

## 1. 설치

설치가 필요 없다. `dist/index.html`을 브라우저(Chrome, Edge, Firefox, Safari 최신판)로 연다. 파일은 브라우저 안에서만 처리되고 서버로 보내지 않는다.

개발·시험에는 Node.js 18 이상이 필요하다. 외부 패키지는 없다.

```
node --test tests/*.test.mjs     # 단위·통합 시험
node scripts/build.mjs           # 웹앱 빌드 (dist/index.html, dist/artifact.html)
node tests/browser.mjs           # 브라우저 시험 (Chrome 또는 Edge 필요)
node scripts/gen-data.mjs        # 합성 CSV와 정답표 재생성
node scripts/evaluate.mjs 300    # 오탐·미탐 평가
node scripts/gen-docs.mjs        # 문서 재생성
```

XLSX·CP949 시험 파일은 `uv run --with openpyxl python scripts/gen-fixtures.py`로 다시 만든다.

## 2. 입력 파일 준비

- 형식: CSV(.csv, .tsv, .txt; 쉼표·세미콜론·탭 구분, UTF-8 또는 CP949) 또는 Excel(.xlsx). 구형 .xls와 암호 보호 파일은 지원하지 않는다.
- 구조: 첫 행은 머리글, 그 아래 한 행이 한 주입의 한 분석물(긴 형식).
- 필드: Sample ID, Sample Type, Analyte, Concentration Level, Nominal Concentration, Peak Area, Internal Standard Area, Retention Time, Dilution Factor, Replicate, Batch ID. 선택 필드로 Injection Order, Parent Sample ID를 쓸 수 있다.
- 필수: Sample ID, Sample Type, Analyte, Nominal Concentration, Peak Area, Batch ID. Analyte와 Batch ID는 열이 없으면 화면에서 고정값을 입력할 수 있다.
- 예시 파일: `data/synthetic_all_batches.csv`, `data/scenarios/*.csv`, `data/synthetic_all_batches.xlsx`.

## 3. 화면별 사용법

### Dashboard
전체 배치 수, 분석 항목 수, QC 경고 수, 검토 필요 시료 수를 보여 준다. 배치 × 분석물 표의 칸을 누르면 해당 QC 검토로 이동한다. 처음 열면 합성 예시 데이터가 들어 있고, 그 사실이 상단 띠에 표시된다.

### Data Import
1. 파일을 고르거나 끌어다 놓는다. XLSX에 시트가 여러 개면 시트를 고른다.
2. **컬럼 매핑**을 확인한다. 머리글 이름으로 자동 연결하며, 이름이 모호하면 "추정: 확인 필요"로 표시한다. 잘못 연결된 항목은 목록에서 바꾼다.
3. **누락 항목과 데이터 문제**를 본다. 숫자가 아닌 값, 음수, 누락은 행 번호와 함께 나오며 값을 채우지 않는다.
4. 인식하지 못한 시료 유형이 있으면 유형을 지정한다. 지정하지 않으면 그 행은 분석에서 빠진다.
5. 희석배수가 비어 있으면 최종 농도를 계산하지 않는다. 모두 1배라면 "희석배수 누락 시 1로 간주"를 켠다.
6. 매핑을 바꾸면 즉시 다시 분석한다. 필수 열이 없으면 분석하지 않고 이유를 보여 준다.

### Calibration
- 배치와 분석물을 고르면 검량선 그래프, 잔차 그래프(역산 편차), 회귀식, 적합성 기준별 판정, 역산 결과 표가 나온다.
- 정량 방식(내부·외부표준법)과 가중치를 바꾸면 그 배치·분석물만 다시 계산한다.
- 적합성은 역산 정확도·수준 수·범위 끝점으로 판정한다. R²는 참고값이다.
- 검량점을 빼려면 "제외…"를 누르고 사유를 적는다. 사유 없이는 제외되지 않는다.
- 가중치 비교 표는 같은 점에 가중치만 바꾼 결과다. 가중치는 분석법에서 정한 것을 써야 한다.

### QC Review
- 항목별 판정, 오류 유형, 관측값, 기준, 출처, 계산 근거를 표로 보여 준다.
- 배치와 분석물을 모두 고르면 QC 통계, 바탕·첨가·중복 표, 내부표준·머무름 시간 그래프가 나온다.
- 항목마다 검토 상태(미검토·확인함·조치 필요·해당 없음)와 메모를 남길 수 있다.
- **QC 기준 설정**을 펼쳐 값을 바꾼다. 기본값은 예시다. 바꾼 내용은 검토 기록에 남는다.

### AI Research Assistant
- 경고 항목마다 **관측 사실**, **가능한 원인(가설)**, **추가 확인 항목**, **권장 검증**, **결론**을 나눠 보여 준다.
- 가설마다 이 데이터 안의 근거, 맞지 않는 점, 판단할 수 없는 부분을 적는다. 결론은 항상 "원인 미확정"이다.
- 게시된 Artifact에서 열면 "Claude에게 해석 요청"을 쓸 수 있다. 엔진의 판정 결과만 보내고 원자료 행은 보내지 않는다. 돌아온 글은 계산 결과에 없는 수치와 단정 표현을 자동 검사해 표시한다.

### Report
- 보고서(HTML), 구조화 데이터(JSON), QC 판정 표(CSV), 정량 결과 표(CSV)를 내보낸다.
- PDF는 HTML 보고서를 브라우저에서 열어 인쇄 → "PDF로 저장"으로 만든다. 로컬에서 열었을 때는 화면의 인쇄 버튼도 쓸 수 있다.
- 검토 메모를 추가하면 검토 기록에 시각과 함께 남는다.

## 4. 결과를 읽을 때

- **기준 미충족**은 설정된 기준을 벗어났다는 뜻이다. 기준이 분석법과 다르면 판정도 의미가 없다.
- **주의**는 기준은 충족하지만 진단상 살펴볼 점이 있다는 뜻이다(예: 검량선은 적합이지만 이상점 후보가 있음).
- **평가 불가**는 필요한 데이터가 없어 계산하지 않았다는 뜻이다. 통과가 아니다.
- 원인 후보는 가설이다. 장비 기록, 크로마토그램, 조제 기록 없이 데이터 표만으로는 원인을 정할 수 없다.

## 5. 분석 엔진을 코드에서 쓰기

```js
import { readTableFile } from './src/parse.js';
import { runRows } from './src/pipeline.js';
import { diagnose } from './src/diagnose.js';
const file = await readTableFile('batch.xlsx', bytes);
const run = runRows(file.sheets[0].rows);            // { built: 검증 결과, result: 분석 결과 }
console.log(run.result.dashboard, run.result.findings, diagnose(run.result));
```

## 6. BioPilot 본편(ELN)으로 보내기

이 도구는 본편과 별개로 브라우저에서만 동작한다. 본편은 "수치 계산은 Python 결정론적 코드"가 원칙이므로, 이 도구의 계산 결과를 본편 화면에 쓰지 않는다. 대신 검증한 배치의 **원자료**를 본편 데이터셋 계약으로 내보내 본편이 다시 계산하게 한다.

- Report 화면의 "BioPilot 본편(ELN)으로 보내기"에서 배치를 고르고 `calibration CSV`, `recovery CSV`를 받는다. 본편 Notebook 탭에서 실험을 만들고 두 파일을 데이터셋으로 올린다.
- 옮기는 것: 검량 표준(`injection_id, level_ng_ml, analyte, analyte_area, is_area`)과 원시료가 연결되지 않은 첨가 시료(`injection_id, sample_id, analyte, spike_ng_g, analyte_area, is_area`).
- 옮기지 않는 것과 이유는 화면에 표시된다: 내부표준 면적이 없는 행, 원시료가 연결된 매질 첨가(본편은 원시료 농도를 빼지 않음), 희석된 첨가 시료, QC·바탕·중복·미지 시료(본편 계약에 해당 열이 없음).
- 단위: 숫자를 그대로 옮긴다. 본편은 조건 블록의 추출 부피와 시료 질량으로 ng/g을 환산하므로, 파일의 첨가 농도가 바이알 내 농도라면 환산 계수가 1이 되도록 조건을 입력한다.
- 명령줄: `node scripts/eln-export.mjs <입력 파일> [배치 ID] [출력 폴더]`. 본편 코드로 대조하려면 저장소 루트에서 `backend/.venv/bin/python qc-validator/scripts/verify_eln_bridge.py <출력 폴더> <배치 ID>`.
