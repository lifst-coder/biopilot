BIOPILOT · 분석 엔진 v1.0.0 · 생성일 2026-11-11 · `node scripts/gen-docs.mjs`가 만든 문서다.

> **모든 기본값은 예시 기준이다.** 허용 기준은 장비·분석법·규격·SOP에 따라 다르다. 실제 판정에는 해당 분석법의 값을 QC Review 화면의 "QC 기준 설정"에 입력해야 한다. 아래 출처는 2026-11에 원문에서 확인한 조항이며, "출처 없음"으로 표시한 값은 이 도구가 정한 진단용 값이다.

- **예시 기본값 (ICH M10 중심)**: 생체시료 정량 분석의 ICH M10 기준을 중심으로, ICH에 수치가 없는 항목은 EPA 537.1·SANTE/11312/2021의 값을 예시로 채웠다.
- **예시: 잔류농약 계열 (SANTE/11312/2021)**: 역산 편차 ±20%, 회수율 70–120%, RSD 20%, 머무름 시간 ±0.1분. 이 문서에서 확인하지 않은 항목은 기본값을 유지했다.
- **예시: 먹는물 PFAS 계열 (EPA 537.1)**: 검량점 ±30%(최저 ±50%), 바탕 MRL의 1/3 미만, 회수율 70–130%, RPD 30%, 내부표준 50–150%. 최근 CCC 대비 70–140% 조건은 구현하지 않았다.

## 3. 계산식

모든 계산은 `src/stats.js`, `src/calibration.js`, `src/qc.js`의 결정론적 함수가 수행한다. LLM은 계산에 관여하지 않는다.

| 항목 | 식 | 비고 |
|---|---|---|
| 응답값 | 내부표준법: 분석물 면적 / 내부표준 면적. 외부표준법: 분석물 면적 | 내부표준 면적이 없거나 0 이하이면 응답값 없음 |
| 가중 선형 회귀 | 응답 = 기울기 × 농도 + 절편, Σw(y − ŷ)² 최소화 | 가중치 가중 없음, 1/x, 1/x², 1/y, 1/y². 기본 1/x² |
| 결정계수 R² | 1 − Σw(y − ŷ)² / Σw(y − ȳw)² | 참고값. 단독으로 적합을 판정하지 않는다 |
| 역산 농도 | (응답 − 절편) / 기울기 |  |
| 검량점 편차 | (역산 농도 − 명목 농도) / 명목 농도 × 100 | 최저 수준에는 LLOQ 허용 편차 적용 |
| 최종 농도 | 장비 측정 농도 × 희석배수 | 희석배수가 없으면 계산하지 않는다(사용자가 "1로 간주"를 켠 경우 제외) |
| 평균, 표준편차 | 표본 표준편차(n − 1) | n < 2이면 표준편차 없음 |
| RSD(%) | 표준편차 / 평균 × 100 |  |
| 상대오차(%) | (측정 − 명목) / 명목 × 100 | QC 정확도 |
| RPD(%) | /a − b/ / ((a + b)/2) × 100 | 2회 측정. 3회 이상은 RSD |
| 회수율(%) | (측정 농도 − 원시료 농도) / 첨가 농도 × 100 | 원시료가 연결되지 않으면 원시료 농도 0(바탕 첨가 방식) |
| 바탕(응답 방식) | 바탕 시료의 분석물 면적 / LLOQ 표준의 평균 분석물 면적 × 100 |  |
| 내부표준 응답(%) | 내부표준 면적 / 검량 표준의 평균 내부표준 면적 × 100 |  |
| 머무름 시간 차이 | 머무름 시간 − 검량 표준의 평균 머무름 시간 |  |
| 추세 | 주입 순서에 대한 단순 선형 회귀의 기울기와 p값 | 주입 순서 열이 없으면 행 순서를 쓰고 그 사실을 표시 |

기준값과 비교할 때는 부동소수점 오차 때문에 경계값(예: 정확히 15.0%)이 뒤집히지 않도록 10⁻⁹ 수준의 여유를 둔다. 경계값은 "기준 내"다.

## 4. 검량선 적합성 판정

R²만으로 판정하지 않는다. 다음을 모두 충족해야 "적합"이다.

1. 농도 수준 수 ≥ `cal.minLevels`
2. 기준 내 검량점 비율 ≥ `cal.minPassPct` (각 점 ±`cal.devPct`%, 최저 수준 ±`cal.devPctLloq`%)
3. 기준 내 농도 수준 수 ≥ `cal.minLevels` (한 수준의 반복 중 절반 이상이 기준 내이면 그 수준은 적합)
4. 최저 수준(LLOQ)과 최고 수준(ULOQ)이 각각 적합
5. 기울기 > 0
6. `cal.useR2`를 켠 경우에만 R² ≥ `cal.r2Min`

명목 농도가 0인 표준은 회귀에 넣지 않는다. 도구는 검량점을 스스로 제외하지 않는다. 제외는 사용자가 사유를 적어야만 가능하고 검토 기록에 남는다.

### 진단(판정과 별개)

- **비선형성**: 같은 가중치로 직선과 2차식을 적합해 F 검정. p < `cal.alpha`이고, 최고 농도에서 2차 항이 1차 항의 `cal.curvatureMinPct`% 이상이며, 최대 역산 편차가 허용 편차의 2/3 이상일 때 경고한다. 2차식은 진단에만 쓰고 정량에는 쓰지 않는다.
- **이상점 후보**: 기준을 벗어난 점 가운데 외적 스튜던트화 잔차의 본페로니 보정 p < 0.05이거나, 그 점을 빼고 적합했을 때 나머지가 모두 기준 내이고 그 점의 편차가 허용 편차의 2배를 넘는 경우.
- **끝점의 모호성**: 이상점 후보가 최저·최고 수준이고 전체 곡률이 유의하면 비선형성으로 보고한다. 끝점 하나만 벗어난 경우 포화와 단일 이상점은 이 데이터로 구별되지 않으며, 진단 문구에 그렇게 적는다.
- **설정 점검**: 내부표준법인데 내부표준 면적 없음, 기울기 음수, 수준 라벨과 명목 농도 불일치, 적용할 수 없는 가중치, 선택한 가중치에서만 저농도가 벗어나는 경우, 검량점 부족.

## 6. 입력 필드와 시료 유형

| 필드 | 한글 | 필수 | 자동 인식하는 머리글 예 |
|---|---|---|---|
| Sample ID | 시료 ID | 필수 | sample id, sampleid, sample name, samplename, sample, name |
| Sample Type | 시료 유형 | 필수 | sample type, sampletype, type, 시료 유형, 시료유형, 유형 |
| Analyte | 분석물 | 필수(고정값 입력 가능) | analyte, analyte name, compound, compound name, component, component name |
| Concentration Level | 농도 수준 | 선택 | concentration level, conc level, level, cal level, std level, 농도 수준 |
| Nominal Concentration | 명목 농도 | 필수 | nominal concentration, nominal conc, nominal, actual concentration, expected concentration, expected conc |
| Peak Area | 피크 면적 | 필수 | peak area, peakarea, area, analyte area, analyte peak area, response |
| Internal Standard Area | 내부표준 면적 | 선택 | internal standard area, internal standard peak area, is area, isarea, istd area, is peak area |
| Retention Time | 머무름 시간 | 선택 | retention time, retentiontime, rt, ret time, analyte retention time, rt min |
| Dilution Factor | 희석배수 | 선택 | dilution factor, dilutionfactor, dilution, df, dil factor, 희석배수 |

| Parent Sample ID | 원시료 ID | 선택 | parent sample id, parent sample, parent id, parent, source sample, 원시료 id |

한 행은 한 주입의 한 분석물이다(긴 형식). 시료 유형: 검량 표준, 검량 바탕, 방법 바탕, QC 시료, 첨가 시료, 중복 시료, 미지 시료. 인식하지 못한 유형 값은 추측하지 않고 Data Import 화면에서 사용자가 지정한다.

### 시료 연결 규칙

- **중복 시료**: 원시료 ID 열 → 같은 Sample ID → `-DUP` 접미사를 뗀 ID 순서로 원시료를 찾는다. 같은 Sample ID의 미지 시료가 2개면 RPD, 3개 이상이면 RSD로 평가한다.
- **첨가 시료**: 원시료 ID 열 → `-MS`, `-SPIKE` 접미사를 뗀 ID. 원시료를 찾지 못하면 바탕 첨가 방식으로 계산하고 그 사실을 계산 근거에 적는다.
- 정량한계 미만 측정이 포함된 중복·반복은 평가하지 않고 "평가 불가"로 보고한다.

## 7. 값을 채우지 않는 원칙

- 숫자가 아닌 값(`N/A`, `<LOQ`, `1,234` 등)은 숫자로 바꾸지 않고 해당 계산에서 제외하며 행 번호를 보고한다.
- 희석배수, 내부표준 면적, 머무름 시간이 없으면 해당 평가를 "평가 불가"로 둔다.
- 필수 열이 없으면 분석을 시작하지 않는다.
- 지원하지 않는 형식(.xls, 암호 보호, 확장자와 내용 불일치)은 오류를 표시하고 기존 데이터를 유지한다.
